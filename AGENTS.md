# Writing reference

Before creating or publishing an article, read `writing/_article-preview.html`,
`writing/post-template.txt`, and the Writing section of `README.md`.

Use the sample to match the article's structure and the shared `styles.css` rules
for fonts, content width, and spacing. Choose an accent color for each article;
keep both light and dark modes readable.

The underscore-prefixed sample is a repository reference. Do not rename it to
a public HTML path or add it to `writing/index.html`. List only articles Arya
has approved for publication.

Keep the navigation's Writing link pointed at `/writing/`. Keep the Substack
button in the social footer pointed at Arya's Substack.
